# Manual classifications for tools/audit/inventory.py.
#
# Format (one per line):   <upstream file> <item> | <category> | <reason>
#
#   <upstream file>  file (or any file of the same stem) the item lives in
#   <item>           qualified name without `Avoid::` (fnmatch globs allowed);
#                    with a parameter list it is matched against the item's
#                    display form, e.g. `Foo::bar(const Point &)`, otherwise
#                    it covers every overload.
#   <category>       debug-output | timer | dead-code | declared-undefined |
#                    subsumed | not-applicable | MISSING | ported
#                    (`ported` = manual mapping for a ported item that has no
#                    resolvable `upstream:` comment; the reason names the Rust
#                    location)
#   <reason>         mandatory one-line reason / description
#
# Only items that are neither mapped by an `upstream:` comment nor by name
# need an entry.  `inventory.py --check` fails on stale entries.
